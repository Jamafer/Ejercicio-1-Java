# Ejercicio-1-Java
CONSOLA
Ingrese la cantidad total de estudiantes: 27 Ingrese la cantidad de estudiantes por equipo: 4 Cantidad total de estudiantes: 27 Estudiantes por equipo: 4 Se pueden formar 6 equipos completos. Quedan 3 estudiantes sin integrar un equipo completo.
Explicación de los operadores
•	/ División entera: calcula cuántos equipos completos se pueden formar. Ejemplo: 27 / 4 = 6.
•	% Módulo o resto: calcula cuántos estudiantes quedan sin equipo completo. Ejemplo: 27 % 4 = 3.
